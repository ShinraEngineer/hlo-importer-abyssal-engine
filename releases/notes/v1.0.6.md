## HeroLab to Foundry (Powered by Abyssal Engine) v1.0.6

Install or update with the manifest URL `https://raw.githubusercontent.com/ShinraEngineer/hlo-importer-abyssal-engine/main/module.json`, or through Foundry's package browser. The module manifest and release zips are now served from this repository, which fixes the 404s on install and update (issue #4).

### Fixes for reported issues

- Duplicate feats (issues #1 and #3). Feats that a background or class grants through its own item list (Bounty Hunter's Experienced Tracker, Munitions Crafter's Alchemical Crafting) are no longer embedded a second time from Hero Lab, and the background skill slot goes to the feat the background actually names.
- Staff and alchemical items (issue #2). The Staff and AlchemicalItem compsets are imported instead of being dropped as unknown; the kitsune Foxfire strike is skipped on purpose because the Foxfire feat already grants it.
- Spellcasting. Re-importing a caster no longer leaves extra Spellbook and Focus Spells entries behind; a spell prepared at two ranks keeps both slots; sorcerers, bards, oracles, psychics, summoners, mystics, and witchwarpers get a spontaneous repertoire; casters with more than one tradition get one entry per tradition.
- Reserves. Focus points and current hit points are read from the fields Hero Lab actually exports, so wounded characters import wounded and the SF2e focus pool is filled.
- Ability scores are used as Hero Lab reports them instead of being re-derived from empty boosts.
- Feat slots take the lowest free slot at or above the feat's level requirement and within the character's level.

### Matcher and parser

- A curated override whose target is missing from the installed packs now falls through to the normal lookup instead of producing a silent miss; the override table is consulted before the canonical index so remastered names win.
- Exact name slugs are tried across all packs before any plural guess; the fuzzy pass keeps the best score across packs.
- Property runes are read only after a potency rune, so items such as Holy Water and Winged Boots keep their names; greater-tier weapon runes are recognised; shield reinforcing runes are written as the numeric tier Foundry expects.
- Frequency periods such as PT1H and P1W, Action1 / Action2 / Reaction costs, silver and duskwood materials, and null item entries in an export are all handled.

### Dialog and API

- The user token is saved on the client after the first successful connection and no longer appears as a cleartext field in module settings; the element token is masked in the conversion log; the conversion log defaults to Info.
- A rejected cached access token is discarded and re-acquired once; the wait Hero Lab attaches to the token response is honoured.
- Each sheet opens its own importer window; a portfolio with a companion no longer overwrites the character's sheet; adopting an existing actor by name requires a matching actor type.

Not in this release: crafting formulas from Munitions Crafter (Hero Lab's export for the reported character carried none; a sample export that includes formulas is needed).
